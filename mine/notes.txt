#--- Will be configurable in next interation ---
1. stop REST
```
exit rest
```

2. Create keys
```
id generate certificate authority where country = !country and state = !state and locality = !city and org = !company_name and hostname = !hostname

id generate certificate request where country = !country and state = !state and locality = !city and org = !company_name and alt_name = !external_ip and hostname =  !hostname and ip = !ip

id sign certificate request where ca_org = !company_name and server_org = !company_name
```
3. Connect to REST service with SSL
```
<run rest server where
    external_ip = !external_ip and       external_port = !anylog_rest_port and
    internal_ip = !ip and internal_port = !anylog_rest_port and
    timeout = !rest_timeout.int and threads = !rest_threads.int and
    ssl = true and ca_org = AnyLog and server_org = !company_name
>
```

Adding User:
```
<id generate certificate request where
    country = US and state = CA and
    locality = "Redwood City" and
    org = "acme-dashboard-user" and
    alt_name = !external_ip and
    hostname = oris-yoga and
    ip = 10.0.0.169 >

<id sign certificate request where
    ca_org = AnyLog and
    server_org = "acme-dashboard-user">

```
